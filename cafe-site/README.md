# Café KUMO（cafe-site）

「この世に存在しないカフェ」の紹介＋モバイルオーダー風サイトの練習用ひな形です。
店名・メニュー・設定はすべて仮のものなので、自由に書き換えてOK！

## ファイル構成

```
cafe-site/
├── index.html   … ページの骨組み（トップ・コンセプト・メニュー・店舗情報・カート）
├── style.css    … 見た目（色は :root でまとめて変えられる）
├── script.js    … メニューのデータ・カート・注文のしくみ
└── README.md
```

## できること（レベル1）

- メニューをカテゴリで切り替え
- 「カートに入れる」→ カートで個数を ＋ / −
- 合計金額の自動計算
- 「注文する」→ 受け取り番号が出る（本当のお金は動きません）
- スマホでは画面下にカートバーが出る

## 練習ステップ

- [ ] **Step 1**：店名・コンセプト文・店舗情報を自分の設定に書き換える（HTML）
- [ ] **Step 2**：`:root` の色を自分のカフェのイメージに変える（CSS）
- [ ] **Step 3**：`script.js` の `menuItems` を自分のメニューに書き換える・増やす
- [ ] **Step 4**：画像を生成して `images/` フォルダに入れ、絵文字と差し替える
- [ ] **Step 5**：「カートの中身を全部消す」ボタンを自分で作ってみる
- [ ] **Step 6（レベル2）**：Stripe のテストモードで「お会計」につなぐ
