# 練習用サイト（practice-site）

かっこいい制作会社サイトを参考に、**自分の手で**作る練習用のひな形です。
文章・色・画像はすべてダミーなので、自由に書き換えてOK！

## ファイル構成

```
practice-site/
├── index.html   … 中身と構造（見出し・文章・リンク）
├── style.css    … 見た目（色・大きさ・配置・アニメーション）
├── script.js    … 動き（メニュー開閉・カーソル・スクロール表示）
└── README.md    … このファイル
```

## 見かた（VS Code）

1. VS Code で `practice-site` フォルダを開く
2. 拡張機能「**Live Server**」をインストール
3. `index.html` を右クリック →「Open with Live Server」
4. 保存するたびにブラウザが自動で更新されます

## 練習ステップ

- [ ] **Step 1**：文章を自分の言葉に書き換える（HTML）
- [ ] **Step 2**：`:root` の色やフォントを変えてみる（CSS）
- [ ] **Step 3**：Works のカードに自分の画像を入れる（`images/` フォルダを作る）
- [ ] **Step 4**：セクションを1つ追加してみる（例：Service）
- [ ] **Step 5**：スマホ表示を確認する（Chrome の検証 → スマホアイコン）
- [ ] **Step 6**：GSAP でスクロール演出を足す
- [ ] **Step 7**：Lenis でスムーススクロールにする
- [ ] **Step 8（上級）**：背景を Three.js（WebGL）に挑戦

## 注意

- 参考サイトのコード・文章・画像はコピーせず、**見て真似して自分で書く**のがルール
- 画像はフリー素材（Unsplash など）を使おう
