# KONOMI（lp-konomi）

どんぐり染めのリネントートバッグ「KONOMI」の商品LP（架空ブランド・練習作品）。
森の工房のとなりに Café Donguri がある、という世界観でつながっています。

## 構成

1. ファーストビュー（浮かぶバッグ・舞い落ちる葉っぱ）
2. こんなこと、ありませんか？（悩みへの共感）
3. ストーリー（スクロール連動でバッグが回転・拡大、工程が順番に出る）
4. カラー切り替え（4色。背景や葉っぱの色まで連動）
5. ビフォーアフター（新品 ⇔ 1年後の経年変化）
6. お客様の声
7. 購入シミュレーター（色・サイズ・個数・名入れ刺繍・ギフト包装 → 割引・送料込みの金額を自動計算）
8. よくある質問（アコーディオン）
9. 最後のひと押し（CTA）
- スマホでは画面下に追従する購入ボタン

## ファイル

- `index.html` … 構成
- `style.css` … 見た目・アニメーション（色は `:root` の変数）
- `script.js` … 色・価格のデータと、すべての仕掛け
- `favicon.svg` … どんぐりのアイコン

## 画像を入れるとき

- バッグは CSS で描いた仮のもの。写真ができたら差し替えてもOK
- ビフォーアフターは `style.css` の `.compare__img--before` / `--after` の background を画像に変える
